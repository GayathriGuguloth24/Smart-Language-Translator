# Smart-Language-Translator

A Smart Language Translator project developed using Python, Langdetect, and Deep Translator. It detects the input language automatically and translates the text into the selected target language.

## Features
- Automatic language detection
- Text translation
- Supports multiple languages
- Simple and easy-to-use interface

## Technologies Used
- Python
- Langdetect
- Deep Translator

## How It Works
1. The user enters text.
2. The application detects the input language.
3. The user enters a target language code.
4. The text is translated into the selected language.

## Example

Input:
Hello, how are you?

Detected Language:
en

Target Language:
te

Output:
హలో, మీరు ఎలా ఉన్నారు?
